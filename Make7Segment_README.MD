# Make7Segment — Usage & Current Python Specification

This repository contains a single utility script to generate a 7-segment digit preview and simple CNC outline toolpaths.

- `Make7Segment.py` — builds chamfered per-segment polygons, optionally unions them with Shapely, and writes SVG, G-code, and optional WebP previews.

Outputs produced (per run):
- `<prefix>.svg` — vector preview (mm units)
- `<prefix>.gcode` — CNC outline toolpaths (straight-line moves following polygon vertices)
- `<prefix>.webp` — raster preview generated by Pillow (optional)

Dependencies
- Python 3
- Optional (recommended): `pillow` for WebP export (`pip install pillow`)
- Optional: `shapely` for boolean union (`pip install shapely`). When available the script can merge segment polygons into cleaner outer contours.

Key CLI options (concise)
- `--height` / `--width` : digit size in mm (defaults: `120.0`, `80.0`)
- `--stroke` : segment thickness in mm
- `--radius` : chamfer radius for chamfer polygon generation
- `--bit` : cutter diameter (used in G-code comments)
 - `--bit` : cutter diameter (used in G-code comments and to scale the green cutting-path stroke in the WEBP preview)
- `--depth` / `--passdepth` / `--board-thickness` / `--cutting-paths` : control cut depth and pass splitting; when `--depth` omitted `--board-thickness` is used as depth.
- `--board-width` / `--board-height` : optional demo board size (defaults: `100.0 x 172.0` mm)
- `--show-board-dim` : emit board/digit reference geometry in the generated G-code and use a single shallow demo pass (does not change SVG/WebP)
 - `--show-board-dim` : emit board/digit reference geometry in the generated G-code and use a single shallow demo pass (does not change SVG/WebP)
 - `--pause-after-seg` : pause the program after each segment (start spindle, cut segment, stop spindle, `M0` pause). Use this to perform per-segment inspections or tool changes.
 - `--pause-after-layer` : pause after each depth layer across all segments when multiple passes are required. The generator performs one depth pass for every segment, then (unless it's the final pass) emits an inter-layer pause (`M5`, `G0 Z<safe>`, `M0`) so you can inspect, clear chips, or change tooling before continuing. Default: off.
 - `--debug-gcode` : when set, the generator will include parenthesized comment lines and extra debug comments in the G-code. Defaults to off (comments suppressed).
- `--gap` / `--overlap` / `--hgap` : geometry tuning for closing seams and shifting verticals
- `--vert-length` : signed delta applied to vertical segment heights (keeps centers fixed)
- `--allow-vertical-overlap` / `--no-allow-vertical-overlap` : allow or clamp vertical growth (default: allow)
- `--hort-length` : override horizontal segment length (must be > 0.0)
- `--rotate` / `--no-rotate` : control 90° rotation applied to G-code coordinates (default: rotated)
- `--spindle-speed` : if set, emits `M3 S<value>` at the start of the G-code
- `--outprefix` : output filename prefix (default `N`)
- `--render-source` : `poly` (default) or `rect` — controls how SVG/WebP are rasterized:
  - `poly`: draw polygon vertices (matches G-code toolpaths)
  - `rect`: draw per-segment rounded rectangles from computed rect params

Pocketing & rough/finish workflow (new)
- `--pocket-middle` : when enabled the generator will remove interior material of each segment using horizontal pocketing scanlines (default: disabled). The pocket scanlines are performed at each depth pass so roughing and pocketing occur progressively as the tool steps deeper.
- `--pocket-step` : lateral spacing between horizontal pocket scanlines in mm. Defaults to `0.9 * bit` when not specified.
- `--rough-bit` / `--rough-step` : when `--pocket-middle` is enabled and a `--rough-bit` value is provided the tool will produce two output G-code files instead of one:
  - `<prefix>_rough.gcode` — uses `--rough-bit` and `--rough-step` (or `0.9 * rough-bit` default) to rapidly remove bulk material with wider stepover.
  - `<prefix>_finish.gcode` — uses the regular `--bit` and `--pocket-step` but will skip middle pocketing (only performs perimeter/profile passes). Run the rough file first, then the finish file.
- Shapely integration: if Shapely is available the pocketing uses precise `LineString` intersections to produce clean horizontal runs; if not available the script falls back to a sampling-based point-in-polygon approach to detect inside runs for each scanline (this fallback is coarser and may produce more short moves).

Config file keys (can be set in `*.cfg` profiles): `pocket-middle`, `pocket-step`, `rough-bit`, `rough-step` (use dashes or underscores).

Additional config keys:
- `pause-after-seg` / `pause_after_seg` : boolean, same behavior as `--pause-after-seg`.
- `pause-after-layer` / `pause_after_layer` : boolean, enable inter-layer pauses (skips pause after the final layer).

Shapely flags
- `--use-shapely` : force boolean union (requires `shapely`)
- `--no-shapely` : disable union and emit per-segment polygons

**Pause Method Details**
- `M0` (Program Pause): stops program execution at that line and waits for user resume (GUI Play or cycle-start `~`). Widely supported by senders and the current method used by `--pause-after-seg`.
- `M1` (Optional Stop): behaves like `M0` but is only honored when the sender/controller's "optional stop" feature is enabled. If optional-stop is disabled, `M1` is ignored.
- Feed-hold / cycle-start (`!` and `~`): real-time sender commands. `!` issues an immediate feed-hold (pause), and `~` resumes. These are not typically embedded for automated pauses because they rely on the sender to send real-time commands rather than being part of the program file.

- Recommendation: keep the default `M0`-based pause for embedded per-segment pauses because it works across most senders (Candle included). If you want configurable behavior, I can add a `--pause-method` option with values like `m0`, `m1`, or `feed-hold` so you can select your preferred pause strategy without editing the script.

Examples
```bash
# polygon-rendered outputs (default render-source)
python Make7Segment.py --height 120 --width 80 --board-width 100 --board-height 172 --show-board-dim

# force union (if shapely installed)
python Make7Segment.py --use-shapely --render-source poly

# rectangle preview instead of polygon rendering
python Make7Segment.py --render-source rect

# adjust verticals and disable rotation
python Make7Segment.py --vert-length 2 --no-rotate

# New examples
```bash
# per-segment pause (start/stop per segment + operator `M0` pause)
python Make7Segment.py --pause-after-seg --show-board-dim

# enable readable G-code comments for debugging
python Make7Segment.py --pause-after-seg --show-board-dim --debug-gcode
```
